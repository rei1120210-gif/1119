# 智光商工 - 數位科技概論 智慧數位學習平台 (期末專題)

依據 108 技術型高級中等學校（高職）課綱設計，專為商業與管理群、外語群等科別之《數位科技概論》打造的現代化線上智慧互動學習入口。

---

## 🌟 核心特色與功能模組

### 1. 📚 數位教材庫與電子書線上預覽 (Chapter & PDF e-Book)
- **涵蓋單元**：
  - **第 3 章 系統平台的組成架構－硬體**（電腦五大單元、CPU架構、機器週期、DRAM vs SRAM、SSD vs HDD、USB/Thunderbolt介面）
  - **第 4 章 系統平台的組成架構－軟體與網路**（系統與應用軟體分類、作業系統比較、雲端運算 IaaS / PaaS / SaaS）
  - **第 5 章 系統平台的運作與未來發展**（Google地圖定位流程、工作排程 FCFS / SJF / RR、人工智慧與物聯網趨勢）
  - **第 6 章 辦公室軟體與影像∕影音軟體**（Office 三大工具、點陣圖 vs 向量圖、Photoshop/Audacity、創用 CC 與 CC0 授權）
- **PDF 線上閱讀**：免額外安裝閱讀器，直接在瀏覽器中翻閱原版教科書 PDF。
- **重點精華整理**：歸納關鍵核心觀念與考試常考精髓。

### 2. 📝 隨堂測驗互動系統 (Interactive Quiz System)
- **真題題庫**：完整收錄隨堂測驗卷第 3 回、第 4 回、第 5 回共 **63 題** 選擇題。
- **模式支援**：
  - ⚡ **全真模擬期末大會考**（隨機抽 20 題）
  - 🎯 **章節專向測驗**（針對特定單元加強）
- **即時回饋**：點擊選項即刻判斷正誤、顯示解析，並同步播放 Web Audio 答對升音和弦 / 錯誤提示音。
- **成績結算報告**：自動評分、分析答對率、記錄歷史最高分。

### 3. 💡 課後習作練習與素養情境題 (Exercise Practice)
- **精選題目**：收錄習作本 **40 題** 課後練習與情境素養題（如手機邊框尺寸判斷、校刊社採購印表機速率 ppm、Linux 發行版本選擇等）。
- **即時解答**：支援點擊即看標準解答與深入觀念剖析。

### 4. 📊 觀念診斷與深度對比表 (Concept Drills)
- **DRAM vs SRAM 記憶體特性深度對比表**（儲存原理、是否需週期性充電、速度、成本與應用）。
- **雲端運算三大架構 (IaaS / PaaS / SaaS) 識別與範例表**。
- **點陣式、噴墨式、雷射印表機技術耗材比較表**。

### 5. 🔊 語音朗讀與音效中心 (Audio Lab & TTS Studio)
- **audio.txt 整合**：預設讀取並提供專屬「智光商工」語音朗讀與全站導覽詞。
- **Web Speech API**：支援全站題目朗讀、章節重點朗讀、語速調整 (0.5x ~ 2.0x) 與音調自訂。
- **Web Audio API**：純前端合成音效（答對升音、答錯警示、滿分號角、按鍵觸發），無需下載任何外部音效檔，完全離線可用。

### 6. 🎨 現代高質感視覺設計
- **深色 / 淺色模式切換**：自動適應系統偏好，一鍵無縫切換。
- **全響應式版面 (RWD)**：桌機、平板、手機皆能完美操作。
- **全域快速搜尋 (Ctrl + K)**：快速檢索章節、關鍵字與題目。

## 🚀 啟動與使用方式

1. **直接開啟**：
   雙擊資料夾內的 `啟動網站.bat` 或直接在檔案總管中雙擊 `index.html`，即可使用預設瀏覽器（Edge / Chrome）開啟。
2. **透過本機伺服器**：
   在該目錄下開啟 PowerShell 或終端機，執行：
   ```bash
   python -m http.server 8080
   ```
   接著在瀏覽器造訪 `http://localhost:8080`。
